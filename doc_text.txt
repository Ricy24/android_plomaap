Objetivo de la práctica Aplicar los dos temas vistos en clase — Provider para gestión de estado y Navigator para el sistema de rutas — en un mini proyecto funcional: una app de catálogo donde el usuario puede ver productos, agregarlos a un carrito y revisar el total a pagar. La app tendrá exactamente 3 pantallas navegables: HomeScreen — catálogo de productos. ProductDetailScreen — detalle de un producto, con botón para agregarlo al carrito. CartScreen — lista de productos agregados y el total de la compra. El estado del carrito (qué productos y cuántos) se maneja con un único ChangeNotifier expuesto mediante Provider, disponible para las tres pantallas sin pasarlo manualmente entre ellas. 2. Modelos de datos 4.1 Product — representa cada producto del catálogo ●  ●  ●    lib/models/product.dart class Product {   final String id;   final String name;   final double price;   final String emoji;     const Product({     required this.id,     required this.name,     required this.price,     required this.emoji,   }); }   const List<Product> catalogo = [   Product(id: 'p1', name: 'Taza de café', price: 25000, emoji: '☕'),   Product(id: 'p2', name: 'Cuaderno', price: 12000, emoji: '📓'),   Product(id: 'p3', name: 'Audífonos', price: 89000, emoji: '🎧'),   Product(id: 'p4', name: 'Mochila', price: 120000, emoji: '🎒'), ]; 4.2 CartModel — el ChangeNotifier que expondremos con Provider Guarda los productos agregados y la cantidad de cada uno. Cada vez que cambia, llama a notifyListeners() para que los widgets que escuchan se actualicen solos. ●  ●  ●    lib/models/cart_model.dart import 'package:flutter/foundation.dart'; import 'product.dart';   class CartModel extends ChangeNotifier {   final Map<Product, int> _items = {};     Map<Product, int> get items => _items;     int get itemCount =>       _items.values.fold(0, (total, qty) => total + qty);     double get total => _items.entries       .fold(0, (sum, e) => sum + e.key.price * e.value);     void add(Product product) {     _items.update(product, (qty) => qty + 1, ifAbsent: () => 1);     notifyListeners();   }     void remove(Product product) {     if (!_items.containsKey(product)) return;     if (_items[product]! > 1) {       _items[product] = _items[product]! - 1;     } else {       _items.remove(product);     }     notifyListeners();   }     void clear() {     _items.clear();     notifyListeners();   } } 5. main.dart — Provider global y rutas con nombre El ChangeNotifierProvider envuelve toda la app, así el CartModel vive por encima del Navigator y no se pierde al cambiar de pantalla. Las rutas se registran con nombre para centralizar la navegación. ●  ●  ●    lib/main.dart import 'package:flutter/material.dart'; import 'package:provider/provider.dart'; import 'models/cart_model.dart'; import 'screens/home_screen.dart'; import 'screens/cart_screen.dart';   void main() {   runApp(     ChangeNotifierProvider(       create: (_) => CartModel(),       child: const MiCarritoApp(),     ),   ); }   class MiCarritoApp extends StatelessWidget {   const MiCarritoApp({super.key});     @override   Widget build(BuildContext context) {     return MaterialApp(       title: 'Mini Carrito',       theme: ThemeData(primarySwatch: Colors.indigo),       initialRoute: '/',       routes: {         '/': (context) => const HomeScreen(),         '/cart': (context) => const CartScreen(),       },     );   } } 6. Pantallas 6.1 HomeScreen — catálogo de productos Muestra la lista de productos. En el AppBar hay un ícono de carrito con una insignia (badge) que usa Consumer<CartModel> para mostrar cuántos productos hay, sin reconstruir toda la pantalla. Al tocar un producto, navega al detalle con Navigator.push y espera el resultado. ●  ●  ●    lib/screens/home_screen.dart import 'package:flutter/material.dart'; import 'package:provider/provider.dart'; import '../models/cart_model.dart'; import '../models/product.dart'; import 'product_detail_screen.dart';   class HomeScreen extends StatelessWidget {   const HomeScreen({super.key});     @override   Widget build(BuildContext context) {     return Scaffold(       appBar: AppBar(         title: const Text('Catálogo'),         actions: [           Stack(             alignment: Alignment.center,             children: [               IconButton(                 icon: const Icon(Icons.shopping_cart),                 onPressed: () => Navigator.pushNamed(context, '/cart'),               ),               Positioned(                 right: 6,                 top: 6,                 child: Consumer<CartModel>(                   builder: (context, cart, _) => cart.itemCount == 0                       ? const SizedBox.shrink()                       : CircleAvatar(                           radius: 9,                           backgroundColor: Colors.red,                           child: Text('${cart.itemCount}',                               style: const TextStyle(                                   color: Colors.white, fontSize: 11)),                         ),                 ),               ),             ],           ),         ],       ),       body: ListView.builder(         itemCount: catalogo.length,         itemBuilder: (context, index) {           final producto = catalogo[index];           return ListTile(             leading: Text(producto.emoji, style: const TextStyle(fontSize: 28)),             title: Text(producto.name),             subtitle: Text('\$${producto.price.toStringAsFixed(0)}'),             trailing: const Icon(Icons.chevron_right),             onTap: () async {               final resultado = await Navigator.push(                 context,                 MaterialPageRoute(                   builder: (_) => ProductDetailScreen(producto: producto),                 ),               );               if (resultado == 'agregado' && context.mounted) {                 ScaffoldMessenger.of(context).showSnackBar(                   SnackBar(content: Text('${producto.name} agregado al carrito')),                 );               }             },           );         },       ),     );   } } 6.2 ProductDetailScreen — detalle y botón “Agregar al carrito” Recibe el producto por constructor. Al presionar el botón, usa context.read<CartModel>() para modificar el estado (sin escucharlo) y luego cierra la pantalla devolviendo un resultado con Navigator.pop. ●  ●  ●    lib/screens/product_detail_screen.dart import 'package:flutter/material.dart'; import 'package:provider/provider.dart'; import '../models/cart_model.dart'; import '../models/product.dart';   class ProductDetailScreen extends StatelessWidget {   final Product producto;     const ProductDetailScreen({super.key, required this.producto});     @override   Widget build(BuildContext context) {     return Scaffold(       appBar: AppBar(title: Text(producto.name)),       body: Center(         child: Column(           mainAxisAlignment: MainAxisAlignment.center,           children: [             Text(producto.emoji, style: const TextStyle(fontSize: 96)),             const SizedBox(height: 16),             Text(producto.name, style: Theme.of(context).textTheme.headlineSmall),             const SizedBox(height: 8),             Text('\$${producto.price.toStringAsFixed(0)}'),             const SizedBox(height: 32),             ElevatedButton(               onPressed: () {                 context.read<CartModel>().add(producto);                 Navigator.pop(context, 'agregado');               },               child: const Text('Agregar al carrito'),             ),           ],         ),       ),     );   } } 6.3 CartScreen — lista del carrito y total Usa Consumer<CartModel> para reconstruirse cada vez que cambia el carrito: lista los productos agregados con su cantidad y muestra el total calculado. ●  ●  ●    lib/screens/cart_screen.dart import 'package:flutter/material.dart'; import 'package:provider/provider.dart'; import '../models/cart_model.dart';   class CartScreen extends StatelessWidget {   const CartScreen({super.key});     @override   Widget build(BuildContext context) {     return Scaffold(       appBar: AppBar(title: const Text('Mi carrito')),       body: Consumer<CartModel>(         builder: (context, cart, _) {           if (cart.items.isEmpty) {             return const Center(child: Text('Tu carrito está vacío'));           }           return Column(             children: [               Expanded(                 child: ListView(                   children: cart.items.entries.map((e) {                     final producto = e.key;                     final cantidad = e.value;                     return ListTile(                       leading: Text(producto.emoji,                           style: const TextStyle(fontSize: 24)),                       title: Text(producto.name),                       subtitle: Text('Cantidad: $cantidad'),                       trailing: IconButton(                         icon: const Icon(Icons.remove_circle_outline),                         onPressed: () =>                             context.read<CartModel>().remove(producto),                       ),                     );                   }).toList(),                 ),               ),               Padding(                 padding: const EdgeInsets.all(16),                 child: Row(                   mainAxisAlignment: MainAxisAlignment.spaceBetween,                   children: [                     Text('Total: \$${cart.total.toStringAsFixed(0)}',                         style: const TextStyle(                             fontWeight: FontWeight.bold, fontSize: 16)),                     ElevatedButton(                       onPressed: () => cart.clear(),                       child: const Text('Vaciar'),                     ),                   ],                 ),               ),             ],           );         },       ),     );   } } 7. Cómo funciona el flujo completo La app arranca y ChangeNotifierProvider crea un único CartModel por encima de MaterialApp. HomeScreen muestra el catálogo. El ícono del carrito en el AppBar escucha el CartModel con Consumer y muestra la insignia con la cantidad. Al tocar un producto, Navigator.push abre ProductDetailScreen y la app espera (await) a que esa pantalla se cierre. En el detalle, el botón usa context.read<CartModel>().add(producto) para agregar el producto sin escuchar cambios, y luego Navigator.pop(context, 'agregado') cierra la pantalla devolviendo un resultado. De vuelta en HomeScreen, ese resultado llega a la variable resultado y se muestra un SnackBar de confirmación. La insignia del carrito ya se actualizó sola gracias a notifyListeners(). Al tocar el ícono del carrito, Navigator.pushNamed(context, '/cart') abre CartScreen, que usa Consumer para listar los productos y calcular el total en tiempo real. Punto clave de la práctica El CartModel nunca se pasa manualmente entre HomeScreen, ProductDetailScreen y CartScreen: al vivir por encima del Navigator, Provider lo mantiene disponible en toda la pila de rutas, mientras que Navigator solo se encarga de mostrar y cerrar pantallas. 8. Cómo ejecutar el proyecto Crear un proyecto nuevo: flutter create mini_carrito Reemplazar el contenido de lib/ con los archivos de este documento, respetando la estructura de carpetas. Agregar provider en pubspec.yaml y ejecutar flutter pub get. Ejecutar la app con flutter run.
